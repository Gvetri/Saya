# GLOSSARY

| Term | Meaning |
|---|---|
| **saya** | the sheath — this repo, which carries and protects the tools |
| **knife** | one installable tool, and the small script that installs it |
| **knife roll** | the whole collection of knives |
| **set** | a cherry-picked list of knives for one kind of host, e.g. `android` |
| **kitchen** | a host / workstation that gets unpacked |
| **unpack** | run a set on a host — `scripts/unpack.sh <set> --apply` |
| **plan** | a dry-run of unpack; the default, and always shown before applying |
